# 跟著 StatQuest 學統計

網站：https://shawntseng.github.io/statquest/

[StatQuest with Josh Starmer](https://www.youtube.com/@statquest) 統計影片的非官方中文學習筆記。給想看懂 A/B 測試、AI 評測這類數字的人：每支影片配一頁白話重點、互動圖和小測驗，看完馬上確認自己是不是真的懂了。

- `index.html`：18 支影片的清單（直接連到 YouTube 原片），進度存在各自的瀏覽器
- `NN-主題.html`：每一支的中文筆記頁，每頁自己就能開，不用其他檔案

影片版權屬原作者。內容的定義以標準統計教科書為準，發現錯誤歡迎開 issue。
